# SmartCrop AI Model Artifacts Directory

This directory stores the trained model weights and metadata generated by the Kaggle training notebooks.

## Required Artifacts Checklist

### 1. Plant Disease Model (`models/disease/`)
- `disease_model.pth` - EfficientNet-B0 PyTorch model state dict or TorchScript weights
- `disease_classes.json` - List/mapping of class indices to disease names (healthy & unhealthy)
- `disease_metrics.json` - Accuracy, F1-score, Precision, Recall, Confusion Matrix stats

### 2. Insect Pest Model (`models/pest/`)
- `pest_model.pt` - Ultralytics YOLO trained weights (best.pt renamed to pest_model.pt)
- `pest_classes.json` - List of IP102 pest class names and IDs
- `pest_metrics.json` - mAP@0.5, mAP@0.5:0.95, precision, recall

### 3. Satellite Crop Model (`models/satellite/`)
- `satellite_model.pkl` - Scikit-Learn Random Forest or Gradient Boosting trained estimator
- `satellite_features.json` - Feature column names, band definitions, and NDVI/NDMI threshold configs
- `satellite_metrics.json` - Classification report, cross-validation scores, feature importance

### 4. Vision-Language Model (`models/vlm/`)
- Configurations and caching for Liquid AI LFM3-VL-2B via Hugging Face.
